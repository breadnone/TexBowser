### Text Only Web Browser  
- Model tested : Qwen2.5 0.5B, Gemma4 e2B.  
- Recommended to to use small mini models only for speed.  
- AI model hosted locally and run via LlamaSharp

### Commands  
- load-mode:"path\to\ggufFile" to load the GGUF model

### Requirements  
- Vulkan capable gpu with at least 8gb vram.
